# Nicola Conci personal academic homepage

Static academic homepage for Nicola Conci, Associate Professor at the Department
of Information Engineering and Computer Science (DISI), University of Trento.

The site is designed as a clean personal research page for Computer Vision,
Artificial Intelligence, Digital Twins, 3D Reconstruction and Multimedia Signal
Processing.

## Files

- `index.html` - homepage content and structure.
- `styles.css` - responsive grey/red academic visual system.
- `script.js` - mobile navigation and section highlighting.
- `assets/nicola-conci.jpg` - local profile photograph.
- `assets/nicola-conci-cv.pdf` - downloadable CV summary based only on the supplied data.

Open `index.html` directly in a browser, or publish the repository root with
GitHub Pages.
